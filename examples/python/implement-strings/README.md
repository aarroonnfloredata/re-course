# Golden example: implement, Python strings

Hand-written reference for the `implement` exercise type. It shows agents what
a good module looks like and is a test fixture for the runtime and validator.

It is laid out as a course workspace with one module:

- `brief.yaml` – course brief (input to the generator)
- `course.yaml` – course metadata the runtime reads
- `sources/` – ingested source excerpts with section IDs
- `modules/01-strings/` – the module, including `solution/` and `broken/`
